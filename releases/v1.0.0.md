# project-template v1.0.0

首个独立稳定版本。提供语言中立的 GitHub 项目治理、AI 协作、安全政策、中文提交规则、跨平台检查、生成和发版工具。

Apache-2.0，保留适用 LICENSE／NOTICE 与上游声明。下载后核验 SHA256SUMS、release-manifest.json 来源及归档内容；不包含运行状态、客户资料、凭证或旧 Git 历史。

治理脚本使用 Python 3.12+；不限定应用语言，不提供应用服务、Docker 镜像或业务示例。生成项目需补充自己的代码测试与现场验收，模板检查不证明业务正确。

远程 CI 与真实发布验收结果将在正式发布说明中列出。正式发布到 GitHub 不等于已部署服务或已发布 PyPI。
